# Klasterisasi dan Sistem Rekomendasi Destinasi Wisata di Indonesia Menggunakan K-Means dan Content-Based Filtering

## Deskripsi

Project ini membahas penerapan metode K-Means Clustering dan Content-Based Filtering untuk mengelompokkan destinasi wisata di Indonesia serta memberikan rekomendasi destinasi berdasarkan karakteristik dan preferensi pengguna.

K-Means Clustering digunakan untuk mengelompokkan destinasi wisata berdasarkan kemiripan karakteristik yang terdapat pada dataset. Sementara itu, Content-Based Filtering digunakan untuk memberikan rekomendasi destinasi berdasarkan kemiripan karakteristik antar destinasi wisata.

## Tujuan

- Mengelompokkan destinasi wisata di Indonesia berdasarkan karakteristiknya.
- Mengidentifikasi kemiripan antar destinasi wisata.
- Mengembangkan sistem rekomendasi destinasi wisata berbasis Content-Based Filtering.
- Membantu pengguna menemukan destinasi wisata yang sesuai dengan preferensinya.

## Metode

### 1. K-Means Clustering

K-Means digunakan untuk membagi destinasi wisata ke dalam beberapa kelompok atau cluster berdasarkan kemiripan karakteristik. Setiap destinasi akan dikelompokkan berdasarkan jaraknya terhadap centroid terdekat.

### 2. Content-Based Filtering

Content-Based Filtering digunakan untuk memberikan rekomendasi destinasi wisata berdasarkan kemiripan karakteristik dengan destinasi yang disukai atau dipilih oleh pengguna.

## Tahapan Project

## Output

- Pengelompokan destinasi wisata berdasarkan karakteristiknya.
- Informasi karakteristik setiap cluster.
- Rekomendasi destinasi wisata berdasarkan kemiripan karakteristik.
- Visualisasi hasil klasterisasi dan rekomendasi.
